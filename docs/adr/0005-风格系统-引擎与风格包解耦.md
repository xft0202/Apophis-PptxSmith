# 风格系统：引擎与风格包解耦，AGENTS参考资料 降级为默认风格包

Status: accepted (2026-09-24，所有者授权研究后定夺）

AGENTS参考资料 中的设计规范拆成两层：**工程质量规则**（量字、对齐基线、色彩纪律上限、不溢出、信息层级）上收到编译/审计层对所有稿件强制；**风格选择**（浅色底、Bento 网格、微软雅黑、克莱因蓝等）下沉为"默认风格包"的内容，可替换、可增删。风格系统对外表现为"风格库"（用户可选、可自定义风格包）。

## Considered Options

- 维持 AGENTS参考资料 为全局强制规范：被否。①抽样 SANDUN 四个案例（北京游/Dify/小米财报/正泰电器）显示其输出为同一套 Tailwind slate+蓝浅色系，浅色 Bento 已是"AI 味"特征，风格单一恰是对标的可乘之隙；②公司汇报场景中客户/企业 VI 优先级高于自家审美；③Anthropic 官方 skill 同样反对模式化版式复用。

## Consequences

- AGENTS参考资料.md 保留为仓库默认风格包资产，但其"纯浅色红线""Bento 强制"条款只对默认包生效，不再约束引擎。
- 风格包 v1 只承诺默认包一个；党政红、咨询深蓝、学术素雅等作为后续候选，每个新包必须过同题测试集验收才能发布。
- 风格包的内容协议（颜色令牌、版式原型、字体清单、图表皮肤）属于待设计项，列入 v0.2 里程碑。
