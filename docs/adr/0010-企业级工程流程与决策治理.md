# 采用企业级工程流程与阶段门治理

Status: accepted (2026-09-24，所有者明示）

Apophis-PptxSmith 是长期维护的企业级开源项目，后续工作必须遵循“产品问题与质量属性 → 技术调查 → 架构评审 → 详细设计 → 受控实现 → 验证硬化 → 发布运营”的阶段门流程。当前仍处于架构决策驱动与技术调查阶段，禁止直接进入生产实现。每个高成本决策必须有唯一 ADR；技术候选必须以真实用户目标、同题语料、PowerPoint/WPS 交付结果、许可证、维护状态和替换成本共同评估。新增证据足以改变结论时，必须重新打开研究票或 ADR，不得为了流程整洁强行维持旧选择。

## Consequences

- Wayfinder 地图先增加“冻结架构决策驱动与质量属性”模块，明确候选方案的评分维度、淘汰条件和 Definition of Ready，再继续前端、后端及基础设施选型。
- 技术选型不再只比较文档引擎；必须分别评估前端交互、后端运行时、文档引擎、任务编排、模型接入、数据/文件、解析/渲染、账号安全、测试、可观测和发布升级。
- 研究性代码只能留在隔离实验中；没有通过架构评审和详细设计的代码不能进入主线。
- 详细规则见 `docs/企业级工程流程与项目治理.md`。
