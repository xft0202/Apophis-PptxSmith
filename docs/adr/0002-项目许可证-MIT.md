# 项目许可证采用 MIT

Status: accepted (2026-09-24，所有者拍板)

项目自身采用 MIT 许可证。依赖政策随之固定为：只引入 MIT/Apache-2.0/BSD 等宽松许可组件；AGPL（PPTist）、专有许可（Dashi 导出包、Anthropic pptx skill 文本）不得作为依赖引入，仅可借鉴思想后自行实现。

## Consequences

- 可复用：cjk-pptx-engine（MIT，验收闸门/量字参照）、PptxGenJS（MIT）、PPT Master（MIT）、GenOffice/OfficeCLI/Presenton（Apache-2.0）。
- 任何引入新依赖的 PR 必须带许可证检查。
