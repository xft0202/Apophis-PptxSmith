# 平台支持矩阵：仅 Linux + Docker 服务端，仅 PC Web 客户端

Status: accepted (2026-09-24，所有者明示）

服务端唯一支持的部署方式是 Linux 服务器上的 Docker（docker-compose）。不支持 Windows/macOS 服务端，不做原生桌面端、不做移动端；客户端仅为 PC 浏览器，且**只支持视口宽度 ≥1440px 的显示器**，低于此宽度不承诺可用（可提示而非适配）。

## Consequences

- CI、依赖选择、文件路径与字体处理均以 Linux 容器为唯一基线，不做跨平台服务端兼容层。
- 前端布局不做响应式与移动端适配：以桌面宽屏（≥1440px）为唯一设计目标，大幅减少 CSS/布局测试矩阵。
- 渲染 QA 链（LibreOffice headless 等）直接运行在容器内；与"真实 PowerPoint 抽检"的关系：抽检发生在开发者/验收者的 PC PowerPoint 上，属于验收流程而非产品部署。
- **字体策略被此决定倒逼**：Linux 容器默认无微软雅黑等商用中文字体（不可随开源项目再分发）。默认风格包必须改用可自由分发的开源字体（思源黑体/Noto Sans SC，OFL）；商用字体由部署者自行上传授权副本，量字引擎按部署环境实际字体文件测量。这是 v0.1 必须实现的部署配置项。
