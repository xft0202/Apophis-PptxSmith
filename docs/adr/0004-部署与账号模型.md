# 部署与账号模型：自托管、支持多用户、部署者可配置模型

Status: accepted (2026-09-24，所有者确认）

项目是长期开源（非商业 SaaS）。部署形态为**自托管**（本地或私有服务器），但需要**账号体系**：支持一人部署、多人使用（典型场景：团队/公司内部署给同事用）。模型层由用户自己配置：LLM 与图像生成模型均可选、可换（provider 注册表 + BYOK），不做积分计费、不做邀请裂变等 SaaS 增长机制。

## Considered Options

- 无账号单用户（最初建议）：被否。所有者明确要求多人共用一个部署实例。
- 多租户商业 SaaS（积分/订阅）：被否。项目定位长期开源非商业。

## Consequences

- 首期即需要轻量账号/权限（管理员 + 成员）与数据隔离边界，但不需要支付、积分、租户级配额。
- 模型配置属于部署侧（环境变量/管理界面），默认提供 OpenAI 兼容接口；模型版本与调用成本计入每份稿件的审计记录。
- 数据处理承诺（文件保存期、删除、模型出境路由）必须写进 README 与产品内说明——这是自托管用户选型时的决策依据。
