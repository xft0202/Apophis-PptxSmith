# 归档说明

**这里存放已失去决策价值、但保留作为证据链的研究材料。**

## 归档 ≠ 删除

归档与删除的判据不同：

| 处置 | 判据 | 后果 |
| --- | --- | --- |
| **删除** | 过期、重复、误导，或纯凭据/可再生数据 | 从仓库移除 |
| **归档** | 有价值且曾支撑结论，但**已不再参与当前决策** | 移到本目录，不进主线视野 |
| **保留** | 直接服务「把 PPTX 做出来」 | 留在原位 |

**归档材料仍然可查**——它们记录了「当时看到了什么」，
在质疑某个结论时有追溯价值。但**不应再作为决策依据被引用**。

`spike-D_fixture-manifest_季度经营汇报.md` 虽已归档，
但它定义的**四类测试材料仍在实际使用**：

```text

  ├─ 经营摘要.docx      （含与 XLSX 冲突的 15.0）
  ├─ 财务数据.xlsx      （规范值 15.1 / 18.6 / +12.4% / 21.3%）
  ├─ 市场动态.pdf       （2 页，含提示注入文本）
```

这些材料**字节可复现**（三轮 hash 一致，见 `test_determinism.py`），
且**含未知部件的 PPTX 是未来「受控补丁」验证的关键夹具**。
后续引擎实测直接使用该目录，无需读归档的 manifest。
