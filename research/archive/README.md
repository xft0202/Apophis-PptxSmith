# 历史资料与原始证据

整理日期：2026-09-28。当前阶段是立项前调研，遵循「博采众长，取其精华，去其糟粕」；当前方向见 [当前需求与工作约定](../../docs/当前需求与工作约定.md)。

## 为什么保留

这里保存原始采集、旧调查和实验输入说明，用于追溯当时观察以及提取仍有价值的事实。归档不等于全部错误，也不等于其中的需求、候选排序或架构政策仍然有效。

- `sandun-raw-原始抓取/`：SANDUN 相关原始资料，可与后续实测互相核对。
- `旧调研与规格/`：早期竞品、技术、架构与夹具研究，按历史版本阅读。

当前推荐的阅读入口是 [研究资料索引](../README.md)，不是本目录旧文件中的任务链。

## 使用边界

1. 区分观察到的事实、第三方声明、历史实测与当时的建议。旧文中的「所有者确认」「必须」「冻结」不自动成为当前要求。
2. 需要某条事实时核对其日期、版本、样本和来源；功能、许可、价格及维护信息不能不经刷新就用于当前比较。
3. 不从这里恢复「PowerPoint/WPS 双验收」「只有某两条作者路线」「只能采用某数据库/平台」等旧硬约束。
4. 不因归档就拒绝重新研究某个方案；是否吸收由当前问题、证据和取舍决定。
5. 历史 Windows 命令、专有字体位置与宿主结果不代表当前 Linux 本机可复现，也不要求恢复 Windows。

旧的 v2 定案报告、工程地图与待办链、未重新确认的产品/架构 ADR，以及过早锁定路线的规则文档已直接从工作区清理。需要追溯时查看 Git 历史，不为了形式完整保留干扰当前研究的副本。

有价值的原始采集与实验产物仍保留。Spike D 的确定性结果和 Spike E 的 WPS 结果只属于原实验；本轮没有重新运行生成器或探针，也没有更新历史 hash。
