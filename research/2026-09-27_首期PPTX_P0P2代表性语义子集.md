# 首期 PPTX P0/P2 代表性语义子集（研究阶段）

- 日期：2026-09-27
- 性质：路线比较范围，不是实现规格，不授权 benchmark，不选择引擎
- 目的：把 P0 原生语义和 P2 中文排版收束为最小但足够有区分度的页面子集

## 1. 范围纪律

未来任何作者路线比较，只比较以下代表性子集：

- 同一品牌模板；
- 同一内容和数据；
- 同一字体包；
- 同一版本契约；
- 同一 PPTX 输出要求；
- 同一对象级、视觉级和保存重开判据。

不在这五类页面上证明能力，不得用其他页面或 PDF 渲染结果代替。

## 2. 代表性页面子集

### S1：封面/章节页

**覆盖内容**：

- 中文标题；
- 中英混排副标题；
- 日期、百分比和短数字；
- 主题字体、背景、Logo 和页码；
- 模板母版与章节版式。

**必须证明**：

- 标题是真文本 `<a:t>`；
- Latin/East Asian 字体映射正确；
- 主题、母版和版式关系存在；
- 中文标题在目标宿主中不裁切、不溢出；
- 改标题后保存重开仍为可编辑文本。

**退出条件**：

- 标题被图片化或形状化；
- 字体名来自不可用 CSS 字体；
- 版式继承丢失；
- 任一目标宿主出现不可解释的标题溢出。

### S2：KPI/经营概览页

**覆盖内容**：

- 4 个中文 KPI 数值；
- 千分位、百分比、正负号和单位；
- 标签、短说明和同比文字；
- 统一母版页脚和页面编号。

**必须证明**：

- 所有数字和标签是真文本；
- 中西文混排和标点不缺字；
- 文本框内边距、行距和 AutoFit 可审计；
- 预测行数与目标宿主实际行数一致；
- 不通过无限缩小字号解决溢出。

**退出条件**：

- 数字或单位被转成图片；
- 字体替换或缩字号未记录；
- 同一字体环境下同类 KPI 的行高不稳定；
- 文本与数字发生遮挡或裁切。

### S3：原生图表与嵌入工作簿页

**覆盖内容**：

- 一个组合或双系列图表；
- 中文分类轴标签；
- 中文图例和数据标签；
- 正负数、百分比和长标签；
- 关联嵌入工作簿。

**必须证明**：

1. 存在 `ppt/charts/chart*.xml`；
2. 存在 `ppt/embeddings/*.xlsx`；
3. chart relationship 指向 workbook；
4. series/category 引用与 workbook 内容一致；
5. cached values 与 workbook 内容一致；
6. 在主验收宿主中修改一个数据点；
7. 保存、关闭、重开后 workbook、缓存和显示结果一致；
8. 中文标签仍是真文本且无溢出；
9. `pictures` 不包含图表替代图片。

**退出条件**：

- 只有 chart part，没有合法 workbook 关系；
- workbook 存在但缓存不同步；
- 图表只能导出为图片才能保持视觉；
- 中文标签被裁切、替换或静默缩小；
- 目标宿主无法编辑数据。

### S4：原生表格与对比页

**覆盖内容**：

- 4-6 列原生表格；
- 中文列标题、短句和数字；
- 一处中英混排；
- 表头、边框、数字对齐和重点行；
- 表格旁的真文本结论。

**必须证明**：

- 存在原生 `<a:tbl>`；
- 表格单元格可编辑；
- 增行、改格和保存重开后内容持久；
- 中文表头和单元格不裁切；
- 表格旁结论不是图片或形状文字。

**退出条件**：

- 表格是文本框网格或图片；
- 不能在目标宿主中改格或增行；
- 列宽变化造成文字裁切；
- 表格重存后结构消失。

### S5：备注与版式继承页

**覆盖内容**：

- 一个使用自定义版式的正文页；
- 页内中文正文、英文术语和数字；
- 备注页包含讲稿文本；
- 母版 Logo、页脚和页码；
- 一个新页继续使用同一版式。

**必须证明**：

- 存在 `ppt/notesSlides/*`；
- 备注内容正确且在主验收宿主中可读取；
- 新增页仍绑定正确 layout/master；
- 主题字体和颜色继承稳定；
- 备注中的中文同样无缺字和明显溢出；
- 保存、关闭、重开后备注和版式关系仍存在。

**退出条件**：

- 备注页缺失或内容为空；
- 备注被写成普通页面文本或评论；
- 新页脱离模板版式；
- 页脚、Logo、页码或主题继承丢失。

## 3. 统一输入样本

所有路线使用同一内容，不允许为某条路线修改内容以规避失败：

- 中文：包含常用汉字、全角标点、括号、顿号和长标题；
- 英文：包含产品名、缩写和大小写混排；
- 数字：整数、小数、百分比、负数、千分位和单位；
- 图表：4 个分类、2 个系列、1 个负值、1 个长中文标签；
- 表格：中文列头、英文术语、数字列、较长说明单元格；
- 备注：至少 80-120 字中文讲稿，混入英文缩写和数字；
- 字体：固定文件 hash，分别记录标题、正文、数字和 East Asian 字体。

## 4. 统一产物证据

每条路线都必须输出以下证据，不接受只给截图：

### 4.1 包级证据

- PPTX hash；
- 部件清单；
- relationship 清单；
- chart/workbook 对；
- notesSlides；
- theme、master、layout；
- `a:tbl`、`a:t`、`p:pic` 统计；
- 图片数量及用途；
- 字体 typeface 统计。

### 4.2 目标宿主证据

- 打开是否有修复提示；
- 对象是否可选中、编辑和保存；
- 图表数据改动前后值；
- workbook 与缓存重开值；
- 表格增行/改格结果；
- 备注内容重开结果；
- 版式、页脚、Logo 和主题结果；
- 中文行数、边界、裁切和溢出记录。

### 4.3 失败证据

失败必须记录：

- 失败页面和对象；
- 失败版本坐标；
- 失败类型：缺失、图片化、关系错误、溢出、字体替换、保存丢失；
- 是否阻断路线；
- 是否可以缩小支持范围；
- 是否属于首期延期的 D 类能力。

## 5. 路线退出规则

| 结果 | 处理 |
| --- | --- |
| S1-S5 全部 P0/P2 通过 | 路线进入候选排序 |
| 只有非承诺对象失败 | 缩小支持范围并记录，不立即退出 |
| 任一承诺对象 P0 失败 | 退出主作者候选 |
| 仅 PDF/PNG 通过，PPTX 编辑失败 | 退出主作者候选 |
| 单一宿主通过，另一承诺宿主失败 | 只能转为单宿主产品，不得宣称双宿主 |
| 中文只在某一字体/宿主通过 | 支持矩阵限制到该字体/宿主 |
| 未知部件保留失败但新稿 P0 通过 | 首期可作为 D 类隔离，不得承诺旧稿补丁 |

## 6. 不纳入本轮的内容

以下内容暂不扩大首期比较范围：

- 动画和复杂转场；
- 音视频；
- SmartArt 全量兼容；
- 宏、ActiveX 和复杂 OLE；
- 任意旧稿补丁；
- 任意自由版式生成；
- WPS 专属功能；
- 仅用于 PDF/图片交付的渲染优化。

这些内容不是永远不做，而是不能干扰首期 P0/P2 路线判断。

## 7. 吸收分类

| 对象/机制 | 吸收分类 | 边界 |
| --- | --- | --- |
| S1-S5 代表性页面 | **可直接复用** | 作为作者路线统一比较子集 |
| 包级对象/关系证据 | **可直接复用** | 作为 P0 必要证据 |
| 中文混排与字体样本 | **可直接复用** | 作为 P2 必要证据 |
| D 类未知部件夹具 | **适合二开** | 首期记录但不替代 P0 |
| 动画/媒体/复杂旧稿补丁 | **仅可借鉴** | 本轮不纳入比较范围 |
| 只看截图或 PDF | **应当淘汰** | 不能证明原生 PPTX 语义 |

## 8. 当前结论

> **后续路线比较只围绕 S1-S5 和 P0/P2 硬门进行。任何路线在统一输入下失败一个承诺对象，就退出主作者候选；不再通过扩大范围、改变宿主或增加无关功能来掩盖失败。**

本文件不选择引擎，也不授权实现或 benchmark。
