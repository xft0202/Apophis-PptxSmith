# 设计开源发布与社区启动方案

Type: grilling
Status: open
Blocked by: 11

## Question

确定如何让项目真正靠“实力、用户口碑和贡献者”长期增长，而不是只把代码放到 GitHub。

必须明确：

- README 首次理解路径、安装成功路径和第一个可验证成果；
- 贡献者如何运行测试、复现 PPTX、添加风格包、改进校准和提交代码；
- 同题测试、审计报告、设计规范和路线图哪些公开；
- 版本支持、破坏性变更、依赖升级、安全问题和 issue triage 规则；
- 如何用真实用户使用后的口碑判断“好用、爱用”，而不是只看 star。

此票不设计商业化机制；项目定位仍是长期开源、非商业 SaaS。
