# 校验与渲染 QA 工具盘点

Type: research
Status: open

## Question

盘点可复用的 PPTX 校验、OOXML 关系检查、内容提取、渲染和视觉差异工具，形成交付闸门候选组合。

重点回答：

- Open XML SDK validation、Open XML schema 检查、LibreOffice headless、OnlyOffice、PowerPoint/WPS 抽检、现有开源 validate 工具各自能证明什么、不能证明什么；
- 如何同时检查容器/关系/内容类型、对象语义、中文溢出、图表可编辑性、渲染差异和未授权变化；
- 哪些工具可以直接复用或二开，哪些只能作为辅助证据；
- Linux Docker 中可稳定运行的最小组合，以及真实 PowerPoint/WPS 人工验收的边界。

输出必须给出证据等级、许可与维护状态，避免把某个渲染器当作目标办公软件真相。
