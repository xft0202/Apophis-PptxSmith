# 设计内容流水线与模型路由

Type: grilling
Status: open
Blocked by: 05

## Question

确定从材料到 PPTX 的内容生产流程：材料解析、澄清门、大纲门、代表页门、内容策划、设计稿、交付门之间的职责与状态转移，并确定 LLM/检索/生图模型如何按阶段路由。

必须回答：

- 材料优先与显式联网检索如何共存；事实、来源、待核实项如何流动；
- 四道门哪些是用户决策、哪些可自动运行、哪些可以跳过；
- 大纲、页面任务、视觉意图和语义对象之间的转换契约；
- LLM、生图、检索、解析器各自的可替换接口与失败回退；
- 如何控制成本、重试、取消、版本和局部重做，而不把用户拖进复杂操作。

目标是形成用户能理解的工作流，不是堆叠 agent 名称。
