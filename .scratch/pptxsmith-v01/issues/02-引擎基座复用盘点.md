# 引擎基座复用盘点

Type: research
Status: open

## Question

在确定文档引擎前，系统盘点并比较可直接复用或二开的成熟方案：DocumentFormat.OpenXml、ShapeCrawler、OfficeCLI、GenOffice、PptxGenJS、PPT Master 及其他相关开源项目。

重点回答：

- 哪些方案能覆盖新稿生成、既有 PPTX 读取、对象级补丁、关系/部件保留、图表缓存与嵌入工作簿同步、结构校验；
- 许可证、维护状态、API 完整度、Linux/Docker 适配、二开成本和社区可持续性；
- 哪些能力应直接复用，哪些适合封装，哪些必须自行补齐；
- 是否存在比“纯 Open XML SDK 自建包装层”更合适的组合。

输出必须区分官方能力、源码线索、实际运行结果和推断，并给出推荐排序与淘汰理由。
