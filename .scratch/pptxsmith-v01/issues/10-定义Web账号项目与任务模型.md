# 定义 Web、账号、项目与任务模型

Type: grilling
Status: open
Blocked by: 01, 05, 06

## Question

确定 Linux Docker 自托管、多用户 PC Web 产品的核心边界：管理员/成员账号、模型配置、项目、材料、任务、版本和审计记录如何组织。

必须明确：

- 一人部署多人使用时的数据隔离、权限和删除边界；
- LLM/生图 provider、密钥、模型路由和成本记录的归属；
- 项目库、版本、阶段门状态、导出文件和审计报告的生命周期；
- 任务排队、取消、失败恢复、并发和存储策略；
- ≥1440px PC Web 的信息架构，不引入移动端或自由画布负担。

不在此票决定具体前端组件库，先锁产品边界和接口责任。
