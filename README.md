# Apophis-PptxSmith

**立项前调研项目**：开展 AI 演示文稿方向的可行性分析、竞品分析、需求分析与技术架构路线分析。当前不是已定案产品，也没有进入生产实现。

## 已确认

- **不限定使用人群**：按演示文稿任务理解需求，不按职业、身份或人群排除使用者。
- **本轮目的地：立项判断与推荐方案**；先形成证据与取舍，不直接进入开发。
- **用户可自由组合与发挥**：研究样例只用于观察和比较，不构成用户必须遵守的任务组合、固定流程、允许清单或能力上限；不在某个样例中不代表不能使用。
- **博采众长，取其精华，去其糟粕**：横向比较多个产品与成熟方案，说明吸收和舍弃的理由，不先锁定技术答案。
- **参考 SANDUN**：交互流程、视觉设计、内容与材料处理、产物与后续修改四维均研究；不照抄，也不排除其他方案。
- **仅在当前本机开发测试**：当前本机为 Linux；不再要求 Windows/WPS COM 或另一台验收机。
- 具体功能、质量承诺、兼容软件、部署形式和技术栈仍待研究与确认。

2026-10-01，所有者已确认**竞品、需求、可行性、技术选型四大块研究收口，不立项**。评价以减少全流程返工为主，按用途判断可用交付；正式开发前仍需获授权的有界完整任务证据。未冻结首期、预算或技术栈，不自动开展实验或开发。
